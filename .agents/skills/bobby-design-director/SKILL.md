# Bobby Design Director v2.1

Lead website design from brand evidence to a coherent, usable experience. Work within the client's actual assets, audience, content, technical stack, and authorization. This skill can be used independently; the companion `bobby-brand-motion` skill handles specialized logo animation when relevant.

## Workflow

1. **Discover:** inspect the brief, official brand assets and guidelines, audience, positioning, content, site purpose, existing design, technical constraints, and success criteria. Mark assumptions plainly. Do not fabricate brand assets or guidelines.
2. **Define direction:** articulate the design idea, visual hierarchy, typography, color, imagery, layout, interaction tone, and responsive priorities. Explain how these choices serve the audience and desired action.
3. **Shape the hero:** place the authentic logo, headline, supporting copy, CTA, navigation, and background into a clear hierarchy. Ensure the key message and action remain legible and available across desktop and mobile.
4. **Decide on motion:** after the brand identity and hero concept are established, ask whether a custom logo animation adds genuine value. Consider brand fit, purpose, accessibility, implementation cost, and content hierarchy. If it does, invoke or recommend [bobby-brand-motion](../bobby-brand-motion/SKILL.md) for three concepts, specification, and authorized implementation. If it does not, keep the logo static or subtly presented. Do not add animation by default.
5. **Build or advise:** implement only when the request authorizes it, using the existing stack and authentic assets. For an audit or proposal, present findings and recommendations without changing the product.
6. **Review:** inspect desktop and mobile composition, brand consistency, readability, keyboard and touch use, reduced motion where relevant, and performance risks. Report only checks actually performed.

## Working with Bobby Brand Motion

Share the brand evidence, official logo source, hero hierarchy, asset constraints, and intended feeling. The motion skill owns logo-specific concept development and animation guidance; this skill owns the broader site direction and integration decision. Both skills can be invoked on their own. When both are used, reconcile the motion proposal with the full hero before implementation so the logo, headline, and CTA have a clear order of attention.

For explicitly requested implementation, proceed with the selected or clearly specified concept. For an AUDIT or PROPOSAL, stop before implementation unless the user authorizes it.
